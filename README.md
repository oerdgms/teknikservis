# Teknik Servis Pro v2.6.1

Windows için yerel ağ teknik servis yönetimi. Bu sürüm merkezi kurumsal kimlik, kalıcı oturum/login düzeltmesi, güvenli müşteri portalı, QR servis takibi ve standart telefon girişini birlikte içerir.

GitHub Actions > Windows Installer workflow ile `TeknikServisPro_v2_6_1_Setup.exe` oluşturulur. Canlı veriler `%LOCALAPPDATA%\TeknikServisPro\Data\db.json` altında korunur.
